# ARGUS — игра для Sony PSP

Изометрическая головоломка-приключение: Аргус, стоглазый страж, уснул, и мир начал
расползаться. Игрок — Око, последний глаз, который не закрылся. Нужно пройти по островам
и разбудить четыре больших глаза. Два финала. Языки: русский и английский.

Двенадцать островов: хаб «Веко», Сад Зеркал (луч и зеркала), Часовые Террасы (поворотные
плиты), Тихая Вода (шлюзы и плоты), Библиотека Сна (память и спящие стражи) и круглый
бонусный остров за просьбы отголосков. Четыре больших глаза, 24 малых, шесть просьб.

Дизайн — `docs/GDD.md`, устройство кода — `docs/TECH.md`, правила для правок — `CLAUDE.md`,
контент и диапазоны идентификаторов — `docs/CONTENT.md`.

## Как запустить на приставке

Homebrew — это не образ диска, а папка с `EBOOT.PBP`. Нужна кастомная прошивка
(на PSP сегодня это ARK; на PS Vita — Adrenaline).

1. Скачать артефакт `ARGUS` из последней успешной сборки GitHub Actions (вкладка Actions,
   workflow `psp-build`) или собрать самому (ниже).
2. Распаковать так, чтобы на карте памяти получилось:
   `ms0:/PSP/GAME/ARGUS/EBOOT.PBP` и рядом каталог `ms0:/PSP/GAME/ARGUS/data/`.
3. Включить PSP, открыть Игра → Memory Stick, запустить ARGUS.

Тот же каталог без изменений открывается в PPSSPP на компьютере и на телефоне:
File → Load, выбрать `EBOOT.PBP`.

## Управление

| Кнопка | Действие |
|---|---|
| Стик или крестовина | идти |
| Крест | взаимодействие: рычаг, зеркало, блок, разговор, надпись, подобрать глаз |
| Круг (удерживать) | взгляд: мир выцветает, спящее замирает, скрытое проявляется |
| L / R | повернуть мир на 90° |
| Квадрат | переключить язык |
| Start | пауза |
| Select | отладочный оверлей (fps, треугольники, куча) |

Прогресс сохраняется сам при открытии большого глаза — в `save.bin` рядом с EBOOT.

## Как собрать

Нужны тулчейн pspdev и Python 3 с pillow, numpy, fonttools. В свежей веб-сессии всё
ставит `ci/session-start.sh`.

```
make test        # юнит-тесты логики на хосте (ASan/UBSan)
make assets      # TOML → меши, уровни, палитры, шрифт, строки, эмбиент
make psp         # EBOOT.PBP + data/ в build/ARGUS
make run-emu SCRIPT=tests/autoplay/smoke.txt   # прогон в PPSSPP headless, PNG в build/shots
make reach                                     # обход островов: до каждого рычага есть дорога
make golden-check                              # сравнение кадров с эталонами tests/golden
```

Автопрогоны (`tests/autoplay/*.txt`) — это скриптованный ввод по кадрам с проверками
прямо в игре: так головоломки проверяются без приставки и без человека. У каждого острова
с головоломкой свой прогон, который её решает и заканчивается открытым глазом;
`perf.txt` проверяет бюджеты кадра на всех островах сразу.

## Как снимать материал

Кадры для роликов удобнее снимать не с приставки, а прогоном в эмуляторе: картинка
та же, но без муара с экрана и без дрожания рук.

1. Написать сценарий ввода по кадрам (`tests/autoplay/*.txt`). Команда `ui 0` убирает
   весь интерфейс, `set eyes 3` выставляет прогресс, `level <остров> <вход>` переносит
   Око куда нужно, `shot <имя>` сохраняет кадр.
2. `make run-emu SCRIPT=tests/autoplay/xmb.txt` — PNG появятся в `build/shots/`.
3. Для видео вместо скриншотов запустить обычный PPSSPP с этим же `EBOOT.PBP`
   и включить его запись экрана; управление тогда своё, а не по сценарию.

Хорошие кадры: облёт острова на заставке, момент, когда луч доходит до приёмника,
открытие большого глаза (вспышка и счётчик), оба финала — рассвет и серость.

## Что внутри

`core/` — чистый C11 без PSP-заголовков: логика, головоломки, построение кадра.
`platform/psp/` — единственное место с sceGu, звуком, вводом и файлами.
`tools/` — Python-инструменты: компилятор уровней, генератор мешей, шрифт, строки, звук.
`levels/`, `assets/` — исходники контента в TOML и CSV; всё, что видно в игре, собирается из них.
