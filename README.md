# ARGUS — демо-сайт сети компьютерных клубов (Оренбург)

Продающее демо для сети из двух клубов ARGUS: живая схема залов с симуляцией
занятости, умный калькулятор тарифов (сам подсказывает выгодный пакет),
прайс, акции, кухня, карта клубов и заявка на бронь. Мобильная версия — приоритет.

Документ для переговоров с владельцем — [BRIEF.md](BRIEF.md).

## Стек и структура

Статика без сборки: HTML-страницы + ES-модули + serverless-функции Vercel.

```
index.html          — главная (hero, зоны, акции, кухня-тизер, карта)
booking.html        — бронирование: схема залов + калькулятор + заявка
kitchen.html        — кухня (меню)
info.html           — цены и правила
admin.html          — админка (демо-PIN 2025): KPI, графики, компы, журнал
privacy.html        — политика конфиденциальности (152-ФЗ)
assets/data.js      — все данные: клубы, зоны, прайс, меню, правила
assets/pricing.js   — калькулятор тарифов (чистые функции, юнит-тесты)
assets/occupancy.js — демо-симуляция занятости; контракт будущего LANGAME-модуля
assets/admin-sim.js — демо-показатели админки (детерминированные)
assets/booking.js   — DOM-слой брони; render.js/ui.js — общие рендеры и навигация
assets/admin.js     — админка: PIN-гейт, графики SVG, журнал в localStorage
api/order.js        — заявка → Telegram (graceful без env)
test/               — node --test, без внешних зависимостей
```

## Запуск и тесты

```bash
npm run dev    # превью на http://localhost:3000
npm test       # юнит-тесты pricing / occupancy / order
```

## Деплой

Vercel, zero-config (статика в корне + `api/`). Переменные окружения
(добавить в настройках проекта, в коде их нет):

- `TELEGRAM_BOT_TOKEN` — токен бота для заявок
- `TELEGRAM_CHAT_ID` — чат владельца

Без них демо работает полностью: заявка логируется предупреждением,
гость видит «заявка принята».

## Интеграция LANGAME

Сейчас бронь ведёт прямыми ссылками на страницы клубов в langame.ru
(у каждой точки своя), занятость мест — детерминированная симуляция
(`assets/occupancy.js`, без Math.random). Боевая интеграция по API
LANGAME Software (ключ у владельца клуба) — замена одного файла
с тем же интерфейсом, см. раздел 5 в BRIEF.md.
