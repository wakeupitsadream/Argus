# Трибуна 56 — трансляции детского спорта в Оренбурге

Сайт-сервис видеосъемки и прямых трансляций детских (10–16 лет) спортивных
матчей. Ключевая механика: каталог предстоящих матчей уже загружен на сайт —
клиент выбирает свой матч, отмечает услуги, и заявка приходит владельцу
в Telegram полностью сформированной.

- Публичная часть: каталог матчей с фильтрами, страницы матчей с embed-плеером
  VK Видео, форма заявки с мгновенным калькулятором стоимости и проверкой
  занятости оператора.
- Админка (`/admin.html`): CRUD матчей, очередь импорта из внешних источников,
  заявки со статусами.
- Импортёр: адаптеры источников расписаний → очередь подтверждения → каталог.

## Стек

Статика без сборки: HTML + нативные ES-модули + `api/*.js` (Vercel
serverless). Без npm-зависимостей. БД — Supabase (Postgres) через PostgREST
REST API обычным `fetch`. Тесты — встроенный `node --test`.

```
tribuna56/
├── index.html        главная (каталог, услуги, форма заявки)
├── match.html        страница матча (/match/:id через rewrite)
├── admin.html        админка (вход по ADMIN_TOKEN)
├── privacy.html      политика конфиденциальности (152-ФЗ)
├── db/schema.sql     схема БД — применяется в Supabase SQL Editor
├── assets/           стили, данные, чистая логика, DOM-слои
├── api/              serverless-функции (+ api/_lib/ — общие хелперы)
└── test/             юнит-тесты (node --test)
```

## Локальный запуск

```bash
npm run dev    # статика на http://localhost:3456 (каталог — демо-данные)
npm test       # юнит-тесты
```

Полный стек локально (serverless + env): `vercel dev` из этой папки.
Без настроенных env всё деградирует молча: каталог показывает демо-данные
на localhost, заявка отвечает «принято» с предупреждением в логах.

## Настройка (один раз)

### 1. Supabase

1. [supabase.com](https://supabase.com) → New project (регион EU).
2. SQL Editor → вставить содержимое `db/schema.sql` → Run.
3. Settings → API: забрать `Project URL` и ключ `service_role`
   (НЕ anon; service_role никогда не попадает в код и браузер — только env).

Особенность бесплатного тарифа: проект «засыпает» после ~7 дней без
API-запросов. Ежедневный cron-импорт (см. ниже) заодно держит его живым.
Если cron отключен и проект уснул — разбудить кнопкой в Dashboard.

### 2. Telegram-бот

1. В Telegram: @BotFather → `/newbot` → получить токен.
2. Написать своему боту любое сообщение, затем открыть
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и взять `chat.id`.

### 3. Vercel

1. New Project → импорт этого git-репозитория.
2. **Root Directory: `tribuna56`**, Framework Preset: Other, без build-команды.
3. Settings → Environment Variables:

| Переменная | Значение |
|---|---|
| `SUPABASE_URL` | `https://<ref>.supabase.co` |
| `SUPABASE_SERVICE_KEY` | ключ `service_role` |
| `TELEGRAM_BOT_TOKEN` | от @BotFather |
| `TELEGRAM_CHAT_ID` | id чата владельца |
| `ADMIN_TOKEN` | `openssl rand -hex 32` — пароль админки |
| `CRON_SECRET` | `openssl rand -hex 32` — Vercel сам шлет его в заголовке cron |
| `VK_SERVICE_TOKEN` | опционально, для VK-адаптеров импортёра |

Cron `0 3 * * *` UTC (8:00 по Оренбургу) подхватится из `vercel.json`.

## Брендинг

Название, контакты, услуги и цены — в `assets/data.js` (константа `BRAND`,
`SERVICES`, `SPORTS`). Палитра — CSS-переменные в начале `assets/styles.css`.
Смена названия = правка одного файла.

## Перед боевым запуском (чек-лист владельца)

- [ ] Реквизиты ИП вписаны в `privacy.html` (желтый блок-черновик удален).
- [ ] Локализация ПД (ст. 18 ч. 5 152-ФЗ): телефоны клиентов хранятся
      в Supabase (серверы ЕС). Для боевой версии — перенос БД на российский
      хостинг ЛИБО режим «ПД только в Telegram» (не писать заявки в БД) —
      решение владельца, обсудить.
- [ ] Согласия на видеосъемку несовершеннолетних — процесс на стороне
      заказчика/организатора соревнований; на сайте есть дисклеймер.
- [ ] Реальные ролики в портфолио вместо плейсхолдеров.
- [ ] Цены услуг в `assets/data.js` проверены.
- [ ] Онлайн-оплаты на сайте нет; если появится — эквайринг + касса (54-ФЗ),
      отдельный проект.

## Переезд в отдельный репозиторий

Папка самодостаточна: перенести содержимое `tribuna56/` в корень нового
репозитория и перепривязать git в настройках Vercel-проекта (Root Directory
станет `./`). Больше ничего менять не нужно.
